
# Digital Bioscience Suite (DBS)

A command-line tool for molecular biology sequence analysis and PCR primer design.

## Features

### DNA/RNA Sequence Analysis
- **Transcription**: Convert DNA sequences to RNA
- **Translation**: Translate RNA sequences to proteins
- **Reverse Complement**: Generate reverse complement of DNA sequences
- **GC Content**: Calculate GC percentage in sequences
- **ORF Finder**: Identify Open Reading Frames with customizable minimum length
- **Codon Usage**: Analyze codon frequency in sequences

### PCR & Primer Tools
- **Tm Calculation**: Calculate melting temperature using Wallace and advanced methods
- **Primer Pair Validation**: Validate compatibility of primer pairs
- **In Silico PCR**: Simulate PCR amplification
- **Primer Design**: Manual primer pair design with automatic validation

### Sequence Management
- Store and manage multiple sequences
- View detailed sequence information
- Organize sequences with custom names
